Hvorfor web-baserede slides?

  • Kan hostes gratis på GitHub Pages
  • Indlejrer interaktive elementer (afstemning, spil, video)
  • Nem deling via URL – også på mobil
  • Fuld kontrol over design og data

Designprincipper

  1. Én idé per slide.
  2. Kontrast & typografi – læsbarhed først.
  3. Rytme – skift mellem oplæg og aktivitet.
  4. Interaktion – spørg, stem, byg sammen.
